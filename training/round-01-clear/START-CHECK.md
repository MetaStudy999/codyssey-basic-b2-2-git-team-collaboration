# B2-2 — 시작 전 지식 체크

이 문서는 B2-2를 시작하기 전에 **Git 협업에 필요한 최소 개념이 준비되어 있는지** 확인하기 위한 자가진단입니다. 공식 평가 점수나 Runtime Gate가 아닙니다.

## 선행 학습

- **필수 선행 미션:** 없음
- **권장 선행 미션:** B2-1
- **있으면 좋은 선행 지식:** Git `add/commit/branch/merge/remote`, GitHub Issue/PR 기초

## 자가진단

- [ ] `git add`와 `git commit`의 역할 차이를 설명할 수 있다.
- [ ] branch를 만드는 이유를 알고 있다.
- [ ] merge가 무엇인지 대략 설명할 수 있다.
- [ ] local repository와 GitHub remote repository의 차이를 알고 있다.
- [ ] GitHub Issue와 Pull Request(PR)의 목적을 구분할 수 있다.
- [ ] 다른 사람의 변경 내용을 review하고 수정 의견을 반영하는 흐름을 이해한다.

## 판단 방법

- 대부분 `예`라면 B2-2 `BEGINNER-GUIDE.md`로 바로 진행합니다.
- 일부가 `아직`이어도 진행할 수 있으며, 필요한 Git 명령과 협업 개념을 가이드에서 보충합니다.
- 개인 프로젝트에서 commit/branch 경험이 거의 없다면 B2-1 또는 작은 연습 저장소에서 먼저 Git 기본 흐름을 익히면 좋습니다.

> **B2-1 CLEAR는 필수 조건이 아닙니다.** 개인 Git 작업 흐름을 이미 이해한다면 바로 B2-2에 진입할 수 있습니다.
