# Simple Deliverable — Utility Functions

Reference는 공식 선택지 A인 **팀원별 유틸 함수 모음**을 권장합니다.

## Runtime 규칙

각 실제 팀원은 자신의 Issue/feature branch/PR을 통해 함수 1개 이상을 추가합니다.

예:

```text
src/
├── string_utils.py
├── math_utils.py
└── date_utils.py
```

함수마다 간단한 docstring 또는 README 사용 예시를 남깁니다.

## 중요한 점

Phase A에서는 `Member1`, `Member2` 이름으로 가짜 기여 commit을 만들지 않습니다. 공식 평가는 **실제 팀원별 Git 기록**을 확인하므로 Runtime에서 각자 직접 기여해야 합니다.
