# B2-2 MAC-V Five-Account Training Simulation

> **TRAINING SIMULATION — NOT OFFICIAL B2-2 EVIDENCE**

이 저장소는 GitHub Account A~E 다섯 계정으로 B2-2 협업 흐름을 반복 연습하기 위한 학습용 저장소입니다.

## 목표

```text
Issue
→ feature/* branch
→ Commit
→ Push
→ Pull Request
→ substantive Review
→ Author feedback 반영
→ Approval
→ Merge
→ Conflict
→ Troubleshooting
→ Simulation Evidence
```

## 계정 최소 목표

각 Account A~E:

- merged PR 2+
- 다른 Account PR Review 2+
- 본인 PR feedback 반영 1+
- simple deliverable contribution 1+
- troubleshooting 참여 1+

팀 전체:

- Issue 10+
- merged PR 10+
- substantive Review 10+
- feedback application 5+
- conflict 2+ / non-trivial 1+
- amend / reset --soft / revert / stash-pop 4종

## 결과물

간단한 Python utility 모음을 사용합니다.

```text
src/
├── math_ops.py
├── string_ops.py
├── date_ops.py
├── list_ops.py

```

각 파일은 미리 완성하지 않습니다. Account A~E가 Issue/feature branch/PR을 통해 실제로 추가·수정합니다.
