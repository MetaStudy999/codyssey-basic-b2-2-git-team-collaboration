# B2-2 미션 지도와 최소 요구

B2-2의 핵심은 복잡한 프로그램이 아니라 **협업 과정**입니다.

```text
Issue
→ feature branch
→ Commit
→ Pull Request
→ Review
→ Feedback 반영
→ Approve / Merge
→ Conflict / Troubleshooting
→ SUBMISSION / Evidence
→ Evaluation
```

핵심 최소 요구:

```text
팀원: 3~5명
팀 저장소: 1개
main: 직접 push 금지 + PR + approve 1+
팀원별: merged PR 2+
팀원별: 타인 Review 2+
팀원별: 본인 PR feedback 반영 1+
팀원별: 결과물 실제 기여 1+
팀 전체: conflict 2+ / non-trivial 1+
팀 전체: amend/reset/revert/stash 4종
모든 팀원: troubleshooting 기록 최소 1개 참여
```

실제 3~5인 팀 GitHub 기록이 공식 Evidence의 기준입니다. 5계정 Simulation은 학습용이며 이를 실제 팀원 활동으로 제출하지 않습니다.
