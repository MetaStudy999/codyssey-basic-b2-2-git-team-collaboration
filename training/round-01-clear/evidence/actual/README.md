# B2-2 R01 — Actual Mission Evidence

이 디렉터리는 **실제 3~5인 팀의 공식 B2-2 Evidence**만 다룹니다.

```text
Actual Team Evidence
≠ Reference
≠ 5계정 Simulation
```

실제 Evidence 후보:

- 실제 팀 Repository URL / 권한
- main Branch Protection 또는 Ruleset
- 팀원별 Issue / merged PR 2+
- 팀원별 타인 Review 2+
- 팀원별 본인 PR feedback 반영 1+
- conflict 2+ / non-trivial 1+
- amend / reset --soft / revert / stash 4종
- 모든 팀원 troubleshooting 참여
- simple deliverable 전원 contribution
- 실제 `SUBMISSION.md`
- 실제 Git graph
- Evaluation 설명

실제 GitHub 서버 기록과 연결되지 않은 템플릿/예시/Simulation 결과를 이 디렉터리에서 공식 PASS Evidence로 승격하지 않습니다.

Secret, Token, Password, Private Key 실제 값은 저장하지 않습니다.
