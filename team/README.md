# Team Introduction Deliverable

B2-2 uses the **team introduction** option as the simple team deliverable.

Each real team member must add one Markdown file named with their GitHub ID, for example:

```text
team/<github-id>.md
```

Each file should contain:

- name or GitHub ID
- role in the exercise
- one Git/GitHub topic they want to practice
- links to their qualifying Issues/PRs after completion

Every team member must contribute at least one real commit to the chosen deliverable. This README is only a scaffold and does not count as a team-member contribution.
