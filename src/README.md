# Source / Example Workspace

B2-2 focuses on the Git collaboration workflow rather than a complex application. The selected simple deliverable for this repository is the `team/` introduction set, so this directory is reserved for any small example code the real team chooses to add during the exercise.

Do not count this scaffold as a team-member contribution. Each real team member still needs at least one actual contribution commit to the selected deliverable and the required Issue → Branch → PR → Review → Merge evidence.
